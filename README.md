<a id="about"></a>
<img src="./assets/section-about.svg" width="100%" alt="01 About" />

I'm **Jaiprasad Pugazhendi**, a full-stack developer based in India. I build web applications end to end: the interface, the API behind it, the database underneath, and the deployment that puts it online.

Most of my public work is small-to-mid sized systems with a real workflow at the centre: a billing and inventory system for a shop, a CRM with a deal pipeline, a habit tracker with streak logic, a browser extension that encrypts user data locally. I'm currently a Full-Stack Developer at **LocalsDen**.

Beyond web apps I'm interested in applied machine learning (computer vision, voice) and in the security side of software: authentication, access control and encryption.

<a id="philosophy"></a>
<img src="./assets/section-philosophy.svg" width="100%" alt="02 Philosophy" />

<table>
<tr>
<td width="33%" valign="top">

**SHIP, DON'T DEMO**<br/>
<sub>A feature is done when it is deployed, authenticated and usable by someone who isn't me.</sub>

</td>
<td width="33%" valign="top">

**ARCHITECTURE FIRST**<br/>
<sub>Decide where state, trust and data live before writing components. Clear layers make later changes cheap.</sub>

</td>
<td width="33%" valign="top">

**SECURE BY DEFAULT**<br/>
<sub>Hash credentials, check roles on the server, validate input, encrypt what is sensitive.</sub>

</td>
</tr>
</table>
