I build web applications end to end: the interface, the API behind it, the database underneath, and the deployment that puts it online. Most of my public work is small-to-mid sized systems with a real workflow at the centre: a billing and inventory system, a CRM with a deal pipeline, a habit tracker with streak logic, a browser extension that encrypts user data locally.

Beyond web apps I'm interested in applied machine learning (computer vision, voice) and the security side of software: authentication, access control and encryption.
